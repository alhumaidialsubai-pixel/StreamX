# StreamX IPTV

تطبيق Android / Android TV لتشغيل قوائم M3U/M3U8 ومصادر HLS التي يملك المستخدم حق استخدامها.

## المزايا
- واجهة عربية RTL وDark Mode.
- تشغيل HLS عبر AndroidX Media3.
- استيراد M3U/M3U8 من رابط.
- بحث وتصنيفات ومفضلة.
- دعم Android TV.
- قنوات HLS تجريبية عامة داخل المشروع.

## البناء
يفضل فتح المشروع في Android Studio. ويمكن بناء APK عبر Gradle أو GitHub Actions.

> التطبيق لا يتضمن اشتراكات أو مصادر بث مدفوعة غير مرخصة.
